## Repository layout

- `apps/*` — executable and deployable applications.
- `packages/*` — reusable libraries and shared domain packages.

## Quality contract

```sh
bun install
bun run quality:fast
bun run quality
```

The stable groups are `quality:static`, `quality:hygiene`, `quality:codebase`, and `quality:test`.
Optional checks are activated by the selected profile and features. The aliases `check`,
`check:full`, and `deadcode` remain available.

See `AGENTS.md` for the complete engineering and collaboration rules.
